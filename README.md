# ALMINGO S.L. – Página web corporativa

## 1. Descripción del proyecto

Este repositorio contiene el desarrollo de la página web corporativa de **ALMINGO S.L.**, una empresa ficticia dedicada al desarrollo de software y soluciones digitales.

La web tiene como finalidad presentar la empresa, dar a conocer sus servicios, mostrar sus proyectos y comunicar su compromiso con la sostenibilidad.

El proyecto se ha desarrollado como parte del reto ALMINGO, correspondiente al ciclo formativo de Desarrollo de Aplicaciones Multiplataforma (DAM).

## 2. Tecnologías utilizadas

Para el desarrollo de la página web se han utilizado las siguientes tecnologías y herramientas:

- **HTML5:** estructura y organización de los contenidos.
- **CSS3:** diseño visual y presentación de las páginas.
- **Visual Studio Code:** entorno de desarrollo.
- **Git y GitHub:** control de versiones y gestión del repositorio.
- **GitHub Desktop:** gestión visual de los cambios y ramas del proyecto.

## 3. Estructura de la web

La página web está compuesta por seis apartados principales:

| Página | Descripción |
|---|---|
| Home | Presentación de la empresa. |
| About Us | Información sobre la empresa, misión, visión, valores y equipo. |
| Services | Descripción de los servicios ofrecidos. |
| Projects | Presentación de proyectos y soluciones digitales. |
| Sustainability | Compromiso con la sostenibilidad y los ODS. |
| Contact | Información de contacto y formulario. |

## 4. Versiones e idiomas

La web dispone de dos versiones:

- **Inglés (EN):** versión principal, desarrollada para cumplir el requisito de orientación al mercado internacional.
- **Español (ES):** versión adicional que permite consultar los contenidos en español.

Ambas versiones mantienen la misma estructura y diseño. Se ha incorporado un selector de idioma en el menú de navegación para facilitar el cambio entre ellas.

## 5. Organización de archivos

El proyecto se organiza de la siguiente manera:

- `home.html`, `about.html`, `services.html`, `projects.html`, `sustainability.html` y `contact.html`: páginas HTML en inglés.
- `home-es.html`, `about-es.html`, `services-es.html`, `projects-es.html`, `sustainability-es.html` y `contact-es.html`: páginas HTML en español.
- `css/`: carpeta que contiene las hojas de estilos CSS.
  - `common.css`: hoja de estilos compartida por las diferentes páginas.
  - Hojas de estilos específicas para cada apartado.
- `imagen/`: carpeta que contiene los recursos gráficos utilizados en la web.

## 6. Visualización del proyecto

La página web no requiere instalación de dependencias ni configuración de un servidor para su visualización.

Para acceder a ella:

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir el archivo `home.html` en un navegador web.
4. Utilizar el menú de navegación para recorrer los diferentes apartados.
5. Utilizar el selector EN/ES para cambiar entre idiomas.
